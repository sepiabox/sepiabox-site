# sepiabox-site

The public website at [sepiabox.com](https://sepiabox.com): what Sepiabox is, how it works and the waiting list.

It is a static site published with GitHub Pages. The app itself lives at `app.sepiabox.com` and its code is in [sepiabox-platform](https://github.com/sepiabox/sepiabox-platform).

## Status

Not published yet. The current design is a page in Portuguese, desktop first, that still reads well on a phone.
